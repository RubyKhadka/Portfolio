# Ruby Kumari Khadka — Portfolio

A responsive, animated AI/Data Science portfolio built as a lightweight static site.

## Files
- `index.html` — page structure/content
- `styles.css` — visual design and responsive styles
- `script.js` — navigation, scroll reveals, cursor effect, and interactions
- `resume.pdf` — add your PDF resume here before deploying

## Before publishing
1. Replace `resume.pdf` with a PDF version of your resume.
2. Add LinkedIn when you have the URL.
3. Replace the three project discussion links with live demos and/or GitHub repositories when available.
4. If you want a profile photo, replace the `RK` avatar block in `index.html`.

## Run locally
Open `index.html` directly in a browser, or use a simple local server such as VS Code Live Server.

## Deploy
This is plain HTML/CSS/JS, so it can be deployed to GitHub Pages, Netlify, Vercel, or similar static hosting.
